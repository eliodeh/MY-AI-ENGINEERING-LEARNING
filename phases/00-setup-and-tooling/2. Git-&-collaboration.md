Git protects your work, branches make experimentation safer, commits record progress, and GitHub lets you share your projects.

## Learning objectives
1. Configure Git: Set your name and email.
2. Track changes: Use git add, git commit, and git push.
3. Use branches: Experiment with new features without breaking your main code.
4. Merge branches: Bring successful changes back into the main branch.
5.  Use .gitignore: Prevent unnecessary files, such as large AI model checkpoints, from being tracked.
6. View history: Use git log to see previous commits and understand how your project has changed.

## Git commands
git config --global user.name "Your Name"	Set your Git name
git config --global user.email "you@example.com"	Set your Git email
git add .	Stage changes
git commit -m "message"	Save a snapshot of staged changes
git push	Upload commits to a remote repository
git branch	List branches
git switch -c feature-name	Create and switch to a new branch
git merge feature-name	Merge a branch into the current branch
git log --oneline	View commit history

The difference between Git and GitHub
- Git: Tracks code changes on your computer.
- GitHub: Hosts remote repositories so you can back up, share, and collaborate on code.
