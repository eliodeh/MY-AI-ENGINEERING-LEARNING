Docker is a tool that packages your application and its dependencies into a container so it can run consistently on different computers.

For example, your AI project might require Python 3.12, PyTorch 2.3, and specific system libraries. Docker helps package these requirements together so your colleague doesn't have to manually recreate your environment.
2. Learning objectives
- Build a Docker image: Use a Dockerfile to define Python, PyTorch, and AI libraries.
- Use volumes: Store code, datasets, and trained models outside the container so they survive container removal.
- Enable GPU access: Configure the NVIDIA Container Toolkit to allow containers to use supported NVIDIA GPUs.
- Use Docker Compose: 
Run multiple connected services, such as an AI inference server and a vector database.
