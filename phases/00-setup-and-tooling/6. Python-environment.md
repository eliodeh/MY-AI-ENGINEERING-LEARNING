This lesson teaches me how to keep each Python project separate so that package conflicts don't break your code.

1. What is dependency hell?
Dependency hell occurs when different projects require incompatible versions of the same library.

Example:
- Project A needs PyTorch 2.4.
- Project B needs PyTorch 2.1.
- Upgrading or downgrading a shared installation can break one of the projects.
Solution: Give each project its own isolated environment.

2. Tools for creating environments
Tool	Purpose
venv	Creates an isolated Python environment.
uv	Manages Python projects, dependencies, and lockfiles.
conda	Manages environments and packages, including some non-Python dependencies.
