# APIs and keys

An API lets your program use a service over the internet. An API key is a secret token that identifies or authorizes your access.

Keep keys private: store them in environment variables or a secrets manager, and never put them in code, notebooks, screenshots, or Git. If a key is exposed, revoke it and create a new one. Check the service's limits and costs before making requests.

**Key takeaway:** Protect API keys like passwords, and load them securely when your program runs.
