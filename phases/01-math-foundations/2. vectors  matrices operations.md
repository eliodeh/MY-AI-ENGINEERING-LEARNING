# The Context:
In this lesson every neural network is matrix multiplication with extra steps. there is a real neural network layer, taking  the lesson of linear algebra intuition.
A matrix is a transformation. @ composes transformations. * is just position-matching (different operation!). Transpose flips dimensions (crucial in backprop). Determinant tells you if a matrix loses information (det=0 = singular = no inverse). Inverse undoes a transformation. Identity does nothing (ResNets use it). Broadcasting stretches bias across batch dimensions automatically. Together, these primitives assemble into y = relu(W @ x + b)


# illustration:
output = relu(weights @ inputs + bias)

# Explanation of operations:
@ = matrix multiply(weights @ inputs)
+ = addition(add bias)
relu = element-wise

def matmul(self, other):
    return Matrix([
        [
            sum(self.data[i][k] * other.data[k][j] for k in range(self.cols))
            for j in range(other.cols)
        ]
        for i in range(self.rows)
    ])

# Build it
class Matrix:
    def __init__(self, data):
        self.data = [list(row) for row in data]
        self.rows = len(self.data)
        self.cols = len(self.data[0])
        self.shape = (self.rows, self.cols)
