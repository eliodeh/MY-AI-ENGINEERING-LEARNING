# Dimensionality Reduction:
this lesson explains it as the proccess of reducing the number of features in a dataset while keeping the most important information.

2. The curse of dimensionality = this curse happens when a dataset has too many features
it also creates three problems:
1. data points become difficult to compare
2. the data becomes spread across a large space
3. need for more data to train a good model.

Solution: reduce the number of dimensions

# the important reduction techniques:
1. PCA = preserves global variance
2. t-SNE = preserves local neighborhoods
3. UMAP = preserves local and some global structure

# summary:
Dimensionality reduction helps computers work with large datasets by reducing unnecessary information while keeping the most important parts.
