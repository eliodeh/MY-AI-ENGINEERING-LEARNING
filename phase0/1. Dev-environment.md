## THE VIRTUAL ENVIRONMENTS AND PACKAGE MANAGERS:
1.  Virtual environment (venv): isolates Python packages for a particular project.
2.  pip: installs and manages Python packages.
3.  npm: manages Node.js packages.
4.  Cargo: builds Rust projects and manages their dependencies.
5.  Dependency: a library or package your application needs to work.


## GPU, CUDA, MPS, and tensors
A GPU can accelerate many AI calculations.
1. CPU: general-purpose processor; sufficient for many beginner exercises.
2. GPU: processor suited to many parallel calculations.
3. CUDA: NVIDIA's GPU-computing platform.
4. MPS: Apple's GPU-acceleration backend for supported devices.
5. Tensor: a numerical data structure used in machine learning.

## Keep your projects reproducible
A reproducible environment means you can recreate your software setup reliably.

Important files include:
1. requirements.txt — records Python package versions.
2.  package.json and package-lock.json — manage and record Node.js dependencies.
3.  Cargo.toml and Cargo.lock — manage Rust dependencies and resolved versions.
4.  .gitignore — excludes files such as .venv/ and __pycache__/ from Git.


## Common errors to avoid
Problem	What to do
Python version is too old	Install a suitable newer Python version.
ModuleNotFoundError	Check that the correct virtual environment is active and the package is installed.
Packages conflict	Use a separate virtual environment for each project.
CUDA is unavailable	Check hardware, drivers, and PyTorch compatibility; use CPU if necessary.
Command is not found	Verify the software installation and terminal PATH.
Project works only on one computer	Record and manage dependencies consistently.
